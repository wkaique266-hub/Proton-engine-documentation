Começar

Instalar e criar seu primeiro projeto

A Proton Engine é um app Android. Cada jogo é um projeto: uma pasta com a cena (o World), as Assets (modelos, texturas, sons, scripts) e as configurações.

Requisitos

  • Android com OpenGL ES 2.0 (praticamente todos os aparelhos atuais).
  • Espaço livre para os projetos e para o APK exportado.
  • WebView do sistema atualizada: os painéis do editor e o runtime de JavaScript usam a WebView.

Passo a passo

  1. Instale e abra o app.

    A tela inicial mostra a lista de projetos.

  2. Toque em criar projeto.

    Dê um nome e escolha um modelo: Vazio (cena limpa) ou FPS (já vem com chão, cubo, câmera do player e controles de toque ligados).

  3. Aguarde a tela de carregamento.

    Na primeira vez a engine organiza as Assets, compila os shaders e instala os scripts de exemplo em scripts/Exemplos.

  4. Pronto: o editor abre.

    Siga para o tour da interface ou direto para o primeiro jogo.

💡

Para começar rápido, crie com o modelo FPS e toque em Play: você já anda com o joystick e olha arrastando o dedo na tela.

Estrutura de um projeto

MeuJogo/
MeuJogo/

Hierarchy

Mostra a Cena principal com três grupos: Skybox e Ambiente (céu, luz e neblina), Objetos e luzes e UI Interface. Filhos aparecem recuados embaixo do pai. O ícone de lixeira remove o objeto (pede confirmação).

  • Tocar: seleciona e mostra no Inspector.
  • Segurar: menu com Attach Parent (escolher filho), Desvincular do pai e Salvar como Prefab.
  • Objetos inativos aparecem esmaecidos.

Inspector

O Inspector muda conforme o tipo de objeto. Num cubo você vê:

  1. Topo: tipo (CUBO), nome e a chave Ativo. O + adiciona scripts.
  2. Transforms: Posição, Rotação (graus) e Escala em X/Y/Z. A seta circular zera.
  3. Material: Surface, Shader (Basic ou Standard) e Color.
  4. Physics: Body (Sem física, Estático, Dinâmico), Collision, Elasticidade, Camada e Máscara.
  5. Texturas e Maps: Materiais prontos, slots Albedo/Normal/Roughness/Metallic/AO e Tiling.
  6. Scripts: lista dos scripts anexados.
ℹ️

As alterações valem na hora para a cena. Use Salvar para gravar no projeto.

Assets

São as pastas reais do projeto. Tem miniatura das imagens, filtros por tipo (Texturas, Materiais, Scripts, Modelos, Prefabs, Sons, Worlds), busca, grade ou lista, e o botão Loja.

  • Tocar numa pasta abre a pasta. Segurar abre o menu: criar pasta, criar script, criar World, importar, renomear, excluir.
  • Tocar num modelo abre o modal de importação. Tocar num .prefab coloca o prefab na cena. Tocar num material.json aplica o material no objeto selecionado.
  • Ao escolher uma textura, som ou script pelo Inspector, aparece a faixa roxa “Escolha…” e só os arquivos do tipo certo ficam acesos.
Começar

Seu primeiro jogo em 10 passos

Um player cápsula que anda com joystick, cai com gravidade, bate em caixas e coleta moedas. Tudo pelo celular.

  1. Crie um projeto Vazio

    Tela inicial › criar projeto › nome “MeuJogo” › Vazio.

  2. Crie o chão

    Toque em + › Primitivos › Plano. No Inspector: Escala X=20, Z=20. Em Physics: Body Estático e Collision Automático.

  3. Dê uma textura ao chão

    Inspector › Texturas e Maps › Materiais prontos › toque em Grama. O tiling é ajustado sozinho.

  4. Crie o Player

    + › Primitivos › Cápsula. Renomeie para Player (o nome importa para os scripts). Posição Y=1. Body Dinâmico, Collision Automático, Elasticidade 0.

  5. Crie a câmera

    + › Câmera › Perspective Camera. Posição (0, 3, -6). Na Hierarchy, segure o Player › Attach Parent › toque na câmera: ela vira filha e segue o player.

  6. Adicione o joystick

    + › UI Interface › Joystick. Abra o Editor de UI (ícone de janela na barra) e arraste o joystick para o canto inferior esquerdo.

  7. Crie o script do joystick

    Assets › segure a pasta scripts › Criar script › nome MoverPlayer. Cole o código abaixo e toque em Salvar.

  8. Anexe o script ao joystick

    Selecione o Joystick na Hierarchy (grupo UI Interface) › Scripts › Adicionar script › escolha MoverPlayer.js.

  9. Coloque obstáculos e moedas

    Loja › Prefabs › Caixote e Moeda › “Na cena”. A moeda já vem com o script de coleta.

  10. Toque em Play ▶

    Mova o joystick. Para voltar ao editor, toque em Stop ■: tudo volta à posição original. Depois toque em Salvar.

scripts/MoverPlayer/MoverPlayer.js
// Anexe este script ao JOYSTICK (UI). Ele move o objeto "Player".
var VELOCIDADE = 4;   // metros por segundo

function update(dt) {
    var p = Engine.find("Player");
    if (!p) return;
    var x = self.input.x || 0;     // -1 (esquerda) .. 1 (direita)
    var y = self.input.y || 0;     // -1 .. 1 (para cima é negativo em alguns aparelhos)
    p.moveAndSlide(x * VELOCIDADE, -y * VELOCIDADE);
    if (Math.abs(x) + Math.abs(y) > 0.1) {
        // vira o player para onde está andando
        p.setRotation(0, Math.atan2(x, -y) * 180 / Math.PI, 0);
    }
}
⚠️

Sem câmera não há Play. Se nada acontecer, abra o Console (ícone >_): erros de script aparecem em vermelho com o arquivo e a mensagem.

💡

Se o player andar “ao contrário”, troque o sinal: use y * VELOCIDADE em vez de -y * VELOCIDADE.

Editor

Criar objetos

Tudo que entra na cena nasce no botão + (Adicionar à cena), na barra de ferramentas.

  1. Toque em + na barra superior.
  2. Escolha a categoria e toque no item. O objeto aparece na frente da câmera do editor e já fica selecionado.
  3. Ajuste no Inspector: nome, posição, material e física.
  4. Salve quando terminar.

Mover, girar e escalar

  • Toque no objeto na cena ou na Hierarchy para selecionar. O gizmo aparece: vermelho = X, verde = Y (para cima), azul = Z.
  • Arraste uma seta para mover naquele eixo, ou digite valores exatos no Inspector.
  • Unidades: 1 = 1 metro. Rotação em graus. Escala 1 = tamanho original.
  • Duplicar (barra superior) copia o objeto selecionado. Desfazer/Refazer funcionam para tudo.

Pai e filho (parenting)

  1. Segure o objeto que será o pai na Hierarchy.
  2. Toque em “Attach Parent — escolher filho”.
  3. Toque no objeto que será o filho. Ele aparece recuado embaixo do pai e passa a acompanhá-lo quando o pai se move.
ℹ️

Para soltar, segure o filho › Desvincular do pai.

Ativo, inativo e excluir

A chave Ativo no topo do Inspector esconde o objeto no Game (sem colisão e sem scripts). Um truque útil: deixe um “modelo” inativo e crie cópias dele com Engine.spawn. Para excluir, use a lixeira na Hierarchy.

Editor

Materiais e texturas

Três jeitos de deixar um objeto bonito: cor, materiais prontos (um toque) e suas próprias imagens.

1. Materiais prontos (o jeito mais rápido)

  1. Selecione um objeto com malha (cubo, esfera, plano, modelo…).
  2. Abra “Texturas e Maps” no Inspector.
  3. Toque numa miniatura em Materiais prontos. Use os filtros (Paredes, Pisos, Natureza, Madeira, Metais…).
  4. Ajuste o Tiling se quiser a textura maior ou menor.

Os 24 materiais procedurais são gerados no próprio celular (funcionam offline) e repetem sem emenda: tijolo, pedra, concreto, madeira, grama, terra, areia, rocha, neve, calçada, asfalto, azulejo, mármore, metal, ferrugem, telha, tecido e outros. Ficam em textures/Materiais/<Nome>/.

2. Texturas reais da Loja (Poly Haven)

Na Loja, aba Texturas online, você baixa centenas de texturas fotográficas com licença CC0 (uso livre, inclusive comercial). Escolha 1K (leve) ou 2K (nítida). Com um objeto selecionado, o botão Aplicar baixa e já aplica.

3. Suas próprias imagens

  1. Importe a imagem nas Assets (segure a pasta textures › Importar) ou use “Abrir com Proton” no gerenciador de arquivos.
  2. Inspector › Texturas e Maps › toque no cartão Albedo.
  3. Escolha a imagem nas Assets (a faixa roxa mostra qual slot está sendo preenchido).
CampoO que faz
ColorMultiplica a textura. Branco mostra a textura original.
ShaderBasic: cor uniforme, sem luz (rápido, estilo cartoon). Standard: recebe luzes e sombras.
AlbedoA imagem da cor do material.
Normal / Roughness / Metallic / AOMapas extras guardados no material (relevo, rugosidade, metal, oclusão).
Tiling X / YQuantas vezes a textura repete. Chão de 20 m com grama: 8 × 8.
💡

Nas Assets, tocar num arquivo material.json aplica aquele material no objeto selecionado.

Física e colisão

Fica em Inspector › Physics. Dois campos principais: Body (como o objeto se move) e Collision (qual forma ele tem para bater).

BodyComportamentoUse em
Sem físicaNão cai e não é empurrado. Ainda pode ter colisão.Decoração, objetos movidos só por script.
EstáticoParado para sempre; os outros batem nele.Chão, paredes, prédios, plataformas.
DinâmicoCai com gravidade, é empurrado e pode ser movido por moveAndSlide, setVelocity e jump.Player, NPC, caixas, bolas.
CollisionForma
Sem colisãoAtravessável.
Automático / Caixa automáticaUma caixa em volta do objeto. Leve e ideal para coisas que caem e rolam.
Model Collider (forma)Só em modelos: a malha vira várias caixas (até 1024) que seguem o formato: chão, paredes, telhado, degraus. Dá para entrar numa casa importada.

Passo a passo: casa importada onde dá para entrar

  1. Importe o modelo (GLB, FBX, DAE…) e toque nele nas Assets.
  2. No modal, em Colisão escolha Model Collider e em Física Estático.
  3. Toque em Importar na cena. O Inspector mostra “Model Collider · N caixas seguindo a malha”.
  4. Coloque o Player dinâmico e dê Play: ele entra pela porta e bate nas paredes de dentro.

Outros campos

  • Elasticidade: 0 = não quica; perto de 1 = quica muito. Para player e NPC use 0.
  • Camada e Máscara: decidem quem colide com quem. Máscara é a soma dos bits (1, 2, 4, 8…; 255 = todas). Os dois corpos precisam permitir o contato.
  • Tecido: deformação elástica visual da malha no Game.

Motor híbrido CPU + GPU

Em Configurações, o Motor híbrido roda a física num núcleo da CPU em paralelo enquanto a GPU desenha, em passo fixo de 60, 120 ou 240 Hz. Assim pulo e colisão ficam iguais em qualquer FPS.

⚠️

Objeto dinâmico com Model Collider usa a caixa geral para se mover. O Model Collider brilha em cenário estático.

Câmera, luzes, Skybox e Ambiente

Câmera do jogo

  1. + › Câmera › Perspective Camera.
  2. Posicione e gire para enquadrar a cena (frente da câmera = eixo +Z).
  3. Para seguir o player, torne a câmera filha do Player (Attach Parent) ou use o script da Loja Câmera 3ª pessoa.

A visão do editor é independente da câmera do jogo. Se você se perder, use Restaurar câmera na barra.

Skybox e Ambiente

Toque em Skybox e Ambiente no topo da Hierarchy. O Inspector mostra os presets de céu, cor/intensidade do sol, neblina e pós-processamento (resolução virtual, pixelado, dither, bloom) para estilos como PS1/PS2/retro.

Editor

Importar modelos 3D

Formatos: GLB e glTF (com animações), OBJ, FBX binário e COLLADA (.dae).

Três jeitos de trazer o arquivo

  1. Abrir com: no gerenciador de arquivos, toque no modelo › Abrir na Proton Engine. Com um projeto aberto ele vai direto para as Assets; na tela inicial a engine pergunta o projeto.
  2. Compartilhar: selecione o modelo e as texturas › Compartilhar › Proton. Tudo vai junto para models/<Nome>/, e as texturas são encontradas automaticamente.
  3. Importar pelas Assets: segure a pasta models › Importar.

O modal de importação

  • 1
    Resumo: triângulos, partes, tamanho em metros e animações.
  • 2
    Malha: “Tudo em um objeto” (mantém animações) ou “Extrair em partes”, em que cada malha/material vira um filho editável.
  • 3
    Colisão: Model Collider (forma), Caixa ou Sem colisão.
  • 4
    Física: Estático, Dinâmico ou Nenhuma.
  • 5
    Ajustes: escala automática (modelos gigantes/minúsculos viram ~2 m) e apoiar no chão.
  • 6
    Importar na cena.
⚠️

FBX em texto (ASCII) não é suportado: no Blender/Max exporte como FBX binário. Ao extrair em partes, as animações (esqueleto) não são mantidas.

Editor

Prefabs

Um prefab é um objeto pronto (com filhos, scripts, materiais e física) salvo como arquivo para reusar.

Criar

  1. Monte o objeto (ex.: inimigo com arma filha e script).
  2. Segure o objeto na Hierarchy › Salvar como Prefab (com filhos).
  3. Pronto: o arquivo aparece em assets/prefabs/<Nome>.prefab. Nomes repetidos viram _2, _3.

Usar

  • No editor: toque no .prefab nas Assets.
  • No jogo: Engine.spawnPrefab("prefabs/Inimigo.prefab", x, y, z).
  • Da Loja: casa, árvore, poste com luz, caixote, barril, cerca, moeda, plataforma móvel e outros.
ℹ️

O prefab é uma cópia: editar o arquivo depois não atualiza os objetos que já estão na cena.

Editor

UI Interface: joystick, botões e HUD

Elementos 2D desenhados por cima do jogo. Criados em + › UI Interface e posicionados no Editor de UI.

ElementoO script recebe em self.input
Joystickx, y de -1 a 1
Slidervalue de 0 a 1
Touch Areadx, dy: quanto o dedo arrastou (ótimo para girar a câmera)
Botãopressed (true/false) e os eventos onPress() / onRelease()
Texto / PainelExibição. Mude pelo script com Engine.ui("Nome").

Passo a passo: botão de pulo + placar

  1. + › UI Interface › Botão, nome BotaoPulo. + › UI Interface › Texto, nome Placar.
  2. Abra o Editor de UI e posicione: botão no canto direito, placar no topo. Escolha estilos (Neon, Vidro, Arcade…).
  3. Crie o script abaixo e anexe ao BotaoPulo (Inspector › Scripts › Adicionar script).
scripts/BotaoPulo/BotaoPulo.js
function onPress() {
    var p = Engine.find("Player");
    if (p && p.grounded) p.jump(6);           // impulso de 6 m/s
}

function update(dt) {
    var placar = Engine.ui("Placar");
    if (placar) placar.setText("Moedas: " + Engine.get("moedas", 0));
}

Métodos de UI: .setText(t), .setVisible(b), .setColor("#fff"), .setBackground("#202020"). Criar pelo script: Engine.createUI({...}).

ℹ️

A UI usa uma referência de 960 × 540 que estica para a tela do aparelho. Teste em pé e deitado.

Editor

Som e música

Sound Player (som 3D)

  1. + › Sound › Sound Player.
  2. Inspector › Arquivo: escolha o som em sounds/. Ajuste Volume, Loop e Tocar ao iniciar.
  3. Escolha o Espaço: Esférico (volume total até o raio interno, some no alcance máximo), Caixa (volume total dentro do Scale do objeto) ou Global (igual em todo lugar, para música).
  4. Opcional: + › Sound › Audio Listener como filho do Player (são os “ouvidos”). Sem Listener, a câmera é usada.

A malha do espaço do som aparece só no editor. Fora do alcance o volume chega a zero e o player é pausado.

Som por script

efeitos e música
Engine.playSound("sounds/pulo.wav", 0.8);      // efeito curto
Engine.playMusic("sounds/tema.mp3", 0.5);      // música em loop
Engine.stopSound("sounds/tema.mp3");
Engine.stopAllSounds();
Engine.find("Radio").audio.play();             // controla um Sound Player

  • Cores: ERROR (vermelho), WARN (amarelo), INFO (azul), SCRIPT (verde, seus Engine.log).
  • Filtros com contagem, busca com destaque, Copiar (para mandar a alguém), Limpar e Rolar automático.
  • Atualiza ao vivo durante o Play.

O botão Diagnóstico (ícone ⓘ) verifica o projeto: câmera faltando, arquivos ausentes, scripts com problema.

Programação

JavaScript: primeiros passos

JavaScript é a linguagem principal de scripts da engine. Cada script é anexado a um objeto (ou elemento de UI) e roda durante o Play.

Criar e anexar um script

  1. Assets › segure a pasta scripts › Criar script. A engine cria scripts/Nome/Nome.js.
  2. Toque no arquivo (ou segure › Editar) para abrir o editor de código.
  3. Escreva o código e toque em Salvar.
  4. Selecione o objeto › Inspector › + › Adicionar script e escolha o arquivo.
  5. Play ▶ para testar. Mensagens aparecem no Console.

Ciclo de vida

FunçãoQuando roda
start()Uma vez, no começo do Play.
update(dt)Todo quadro de script (~30 vezes/s). dt = segundos desde o último update (máx. 0,1).
lateUpdate(dt)Depois de todos os update. Bom para câmera.
onCollisionEnter(nome) / onCollisionExit(nome)Começou/terminou de encostar em outro objeto.
onMessage(msg, dados, de)Recebeu Engine.send(...) de outro script.
onPress() / onRelease()Botão/UI pressionado e solto.
scripts/Girar/Girar.js
var tempo = 0;                       // variáveis do arquivo persistem entre updates

function start() {
    Engine.log("Iniciou: " + self.name);
}

function update(dt) {
    tempo += dt;
    self.rotate(0, 45 * dt, 0);                   // 45 graus por segundo
    self.position.y = 1 + Math.sin(tempo) * 0.2;  // flutua
}

function onCollisionEnter(outro) {
    if (outro === "Player") Engine.log("O player encostou!");
}
⚠️

Sempre multiplique movimentos por dt: assim a velocidade é a mesma em qualquer aparelho. Exceção: moveAndSlide(vx, vz) já recebe velocidade em m/s, então não multiplique por dt.

function update(dt) {
    var me = Engine.find(self.id);

    }
}

Programação

Scripts em Java

Para quem prefere Java: a engine compila o código no próprio celular (em DEX) e carrega no Play. Também vai junto no APK exportado.

Regras do arquivo

  • Classe public, sem package.
  • Nome da classe igual ao nome do arquivo (Girar.java → public class Girar).
  • Herda de ProtonBehaviour.
scripts/GirarJava/GirarJava.java
public class GirarJava extends ProtonBehaviour {

    float total = 0;

    @Override
    public void start() {
        log("Java iniciou!");
    }

    @Override
    public void update(float deltaTime) {
        total += deltaTime;
        self.rotate(0, 45 * deltaTime, 0);     // 45 graus por segundo
        if (total > 5) {
            self.jump(5);                      // pula a cada 5 s
            total = 0;
        }
    }

    @Override
    public void stop() {
        log("Java parou.");
    }
}

Passo a passo

  1. Crie o arquivo .java nas Assets (Criar script e trocar a extensão, ou importar).
  2. Abra e toque em Salvar. A engine compila sozinha: aparece uma faixa amarela (compilando), verde (ok) ou vermelha (erro com linha e mensagem). Log completo em bin/java/compile.log.
  3. Anexe ao objeto pelo Inspector › + › Adicionar script.
  4. Play. Pause suspende o update; Stop chama stop().

API disponível

MembroDescrição
start() · update(float deltaTime) · stop()Ciclo de vida.
self.translate(x,y,z) · self.rotate(x,y,z)Mover e girar somando.
self.moveAndSlide(vx, vz) · self.jump(força)Movimento físico.
log(t) · warn(t) · error(t)Mensagens no Console.
⚠️

A API Java é menor que a de JavaScript (sem find, spawn, UI e save). Para lógica de jogo completa use JavaScript; use Java para cálculos pesados e código que você já tem. Não roda em UI nem em objetos criados por spawn/prefab durante o Game. Loop infinito trava o app: não há tempo limite.

Exportar o jogo como APK

  1. Salve a cena e confira se há uma câmera ativa.
  2. Toque em Exportar (seta para baixo na barra).
  3. Preencha: Nome do aplicativo e Pacote (ex.: com.seunome.meujogo, único por jogo).
  4. Importar ícone (opcional): uma imagem quadrada.

  6. Instale pelo gerenciador de arquivos (permita “fontes desconhecidas”).
⚠️

A exportação é experimental e usa assinatura de teste: ótima para testar e mandar a amigos, mas para a Play Store você precisará assinar com a sua própria chave. Se algo falhar, toque em Ver / copiar log APK.

O APK leva as Assets usadas, scripts JS/Py e os DEX dos scripts Java aplicados. As configurações de FPS e o motor híbrido vão junto.

Problemas comuns

Dei Play e nada acontece

Falta uma câmera, ou o script tem erro: abra o Console.

Meu objeto cai infinitamente

O chão precisa de Body Estático e Collision Automático. O objeto que cai precisa de Collision diferente de “Sem colisão”.

Não consigo entrar na casa que importei

Troque a Collision do modelo para Model Collider (forma).

Engine.find devolve null

O nome precisa ser exatamente igual (maiúsculas contam) e único. O objeto pode estar destruído ou o clone ainda não apareceu (espere um update).

O player atravessa paredes ou treme

Use moveAndSlide em vez de mudar position direto em corpos dinâmicos. Ligue o Motor híbrido com física a 120 Hz.

Textura muito esticada

Aumente o Tiling em Texturas e Maps.

Modelo gigante ou invisível

Reimporte com Ajustar tamanho automaticamente ou mude a Escala. Use Restaurar câmera para reencontrar a cena.

FBX não abre

Exporte como FBX binário (7.x) ou prefira GLB.

FPS baixo

Modo Turbo, resolução 75% ou menor, menos luzes de ponto, texturas 1K e o Shader Basic em objetos distantes.
